# Inner Bloom

Create a premium mobile app called “Legato”.

Legato is a grief support app for:

- loss of a person

- loss of an animal

- fear of losing someone

- anxiety / reflection around death

- “I don’t know yet”

This is NOT a generic wellness app, not a productivity app, not a childish app, and not a dark memorial app.

The app must feel:

- premium

- editorial

- soft but not sad

- organic

- luminous

- emotionally intelligent

- calm

- highly readable

- minimal but not empty

Visual inspiration:

- high-end editorial mobile interfaces

- strong typography hierarchy

- generous whitespace

- refined serif + clean sans serif

- warm off-white backgrounds

- muted peach / dusty rose / pale sage / mist blue / lavender haze accents

- subtle gradients

- soft blurred organic halos

- sculptural rounded blocks

- luxurious but quiet

Avoid:

- clutter

- generic startup UI

- too many small cards

- childish illustrations

- wellness clichés

- heavy gamification

- gloomy grief visuals

Main app structure:

- Home

- Garden

- Help

- Space

The app works through:

1. Entry branch

2. Interface mode

3. Modules

Entry branches:

- loss of a person

- loss of an animal

- fear of losing someone

- death anxiety / reflection

- I don’t know yet

Interface modes:

- Cocoon = overwhelmed / low-energy / fewer options

- Anchoring = fog / dissociation / more structure

- Breath = slight reopening / more air / more visual calm

- Relay = practical support / help from others

Important:

The app must keep one coherent design system.

Branches and modes should change priorities, tone, and layout density, but still feel like one product.

Core modules:

- Presence AI

- No words mode

- Practical help

- Garden

- Garden detail

- Sensitive dates

- Memory library

- Settings

- Crisis / ultra-low-energy mode

Very important:

The Garden is planted for the lost being.

It is not a cute companion.

It is not a game.

It becomes a symbolic inner landscape the user can walk through, revisit, and populate with traces:

- voice

- photo

- sentence

- habit

- object

- place

- date

Generate:

- onboarding

- 5 home variants

- 4 mode variants

- AI presence screen

- no words screen

- help screen

- garden overview

- garden zone detail

- sensitive dates

- memory library

- settings

- crisis screen

For each screen:

make it obvious:

- what the user sees

- what they can do

- what happens next

The result should feel like:

a quiet, beautiful, emotionally intelligent interior space.

Not a sad app.

Not a generic self-care app.

A refined emotional companion with a living garden at its center.
