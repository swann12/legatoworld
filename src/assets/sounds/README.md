# Démonstrations Legato — D4
Les six ambiances sont des synthèses originales créées pour ce projet, sans échantillon ni composition préexistante. Les quatre textes guidés sont originaux et rendus par eSpeak NG (voix synthétique, pas une voix humaine enregistrée). Aucun enregistrement tiers ou voix clonée. Ces fichiers sont des démonstrations ; les sons de nature sont synthétiques et les guides sont répétés pendant la durée choisie. Les données vocales eSpeak NG et leur moteur sont distribués sous GPL ; aucun moteur n'est embarqué dans l'app, seulement sa sortie sonore. La sortie vocale n'est pas soumise à la licence du programme (FAQ eSpeak).

Le lecteur prépare un fichier WAV fini, mélange et fondu inclus, puis le lit par un élément audio natif. L'arrêt et le fondu sont dans le fichier, sans dépendre d'un minuteur JavaScript d'arrière-plan. Toute la nuit utilise une boucle sans fin. Le téléphone peut interrompre l'audio selon son navigateur/OS ; aucun essai sur appareil verrouillé n'est certifié. « Éteindre l'écran » assombrit la page, ne verrouille pas physiquement le téléphone.
